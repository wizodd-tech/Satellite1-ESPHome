# Sound effects

The sound effects built into the firmware (`wake_word_triggered.flac`, `mute_switch_on.flac`,
`mute_switch_off.flac`, `timer_finished.flac`, `jack_connected.flac`, `jack_disconnected.flac`,
`factory_reset_initiated.mp3`, `factory_reset_cancelled.mp3`) are from:

[Home Assistant Voice Preview Edition Sounds](https://github.com/esphome/home-assistant-voice-pe/tree/dev/sounds)
© 2024 by [Clayton Charles Tapp](https://www.cctaudio.com/), licensed under
[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

They are used unmodified. The build fetches them from FutureProofHomes' firmware assets; on 2026-10-13 all
eight files were byte-for-byte identical (MD5) to the files of the same names in the repository linked above.
